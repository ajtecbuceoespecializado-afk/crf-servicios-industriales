# CRF Servicios Industriales SpA — sitio inicial

Sitio web estático para GitHub Pages. Incluye `index.html`, `styles.css`, `script.js` y el logo facilitado por el cliente en `assets/logo-crf.png`.

## Publicación
1. Crear repositorio **nuevo**, separado del de AJTEC (por ejemplo `crf-servicios-industriales`).
2. Subir **el contenido de esta carpeta** a la raíz del repositorio.
3. Settings → Pages → Deploy from a branch → `main` / `/(root)` → Save.
4. Una vez publicada la web, configurar el dominio personalizado `crfserviciosindustriales.cl` en Settings → Pages.
5. Configurar los registros DNS para GitHub Pages en Cloudflare según la documentación oficial vigente de GitHub, verificando que no haya registros conflictivos.
6. Habilitar HTTPS cuando el certificado esté disponible.
